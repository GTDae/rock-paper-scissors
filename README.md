# Rock Paper Scissors

The Odin Project, Foundations, [Rock Paper Scissors](https://www.theodinproject.com/lessons/foundations-rock-paper-scissors) project.

Console-only version per the lesson spec — no DOM/UI yet, that's a later lesson (Revisiting Rock Paper Scissors). Built to spec first, one commit per step; unique extras (if any) come after, clearly marked.

Open `index.html` in a browser and play via the console — `getHumanChoice()` uses `prompt()`.
