# Rock Paper Scissors

The Odin Project, Foundations, [Rock Paper Scissors](https://www.theodinproject.com/lessons/foundations-rock-paper-scissors) project.

Console-only version per the lesson spec — no DOM/UI yet, that's a later lesson (Revisiting Rock Paper Scissors). Built to spec first (commits A-F), then three unique extras on top (commits G-I):

- **Best-of-N** — choose 1, 3, 5, 7, or 9 rounds at the start; the game ends as soon as either side clinches the majority rather than always playing every round
- **Round recap** — a clean round-by-round summary printed before the final score
- **Trash talk** — a few randomised lines per outcome (win/lose/tie), so it doesn't say the same thing twice in a row

Open `index.html` in a browser and play via the console — `getHumanChoice()` and `getRoundsToPlay()` both use `prompt()`.

Live: [gtdae.github.io/rock-paper-scissors](https://gtdae.github.io/rock-paper-scissors/)
